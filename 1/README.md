# Minecraft 世界状态记录与还原脚本

这是一个用于 Minecraft Bedrock Edition 的脚本，可以记录和还原特定范围内的世界状态，包括方块、实体和游戏时间。

## 功能特点

- 记录和还原指定范围内（13x13x13）的所有方块
- 记录和还原范围内的生物实体
- 保持原有实体的存在，只还原记录的实体
- 还原游戏时间
- 使用标签系统追踪实体
- 批量处理方块以提高性能
- 支持中文命令

## 使用方法

### 命令列表

- `test` - 记录当前世界状态
- `回溯` - 还原到上次记录的世界状态

### 记录的内容

1. 方块信息
   - 类型
   - 位置（x, y, z坐标）
   - 包括空气方块

2. 实体信息
   - 类型
   - 位置
   - 生命值
   - 不包括玩家和掉落物

3. 游戏时间
   - 游戏天数
   - 当天时间（tick）

## 技术细节

### 方块还原机制

- 按方块类型分组
- 查找连续区域进行批量还原
- 使用 `fill` 命令提高效率
- 每100个方块添加短暂延迟避免卡顿

### 实体还原机制

- 使用 `recorded_entity` 标签标记记录时存在的实体
- 优先使用原位置的实体（1格范围内）
- 其次尝试传送附近的同类型实体（10格范围内）
- 如果找不到合适的实体则重新生成
- 使用临时标签避免实体重复传送
- 清除记录时不存在的实体（通过标签识别）

## 限制和注意事项

- 记录范围限制为以玩家为中心的13x13x13区域
- 需要足够的权限执行命令
- 实体还原基于类型和位置匹配
- 不会影响玩家和物品实体
- 会清除记录后新生成的实体（不包括玩家和物品）

## 已知问题

1. 实体还原相关
   - 无法准确将实体还原到记录时的位置
   - 无法完全还原记录时的生物种类及数量
   - 某些特殊实体可能无法通过 summon 命令生成
   - 实体的特殊状态（如羊毛颜色、村民职业等）暂不支持还原
   - 实体的装备和物品栏内容不会被保存
   - 某些实体可能会在生成时出现高度偏差

2. 方块还原相关
   - 部分方块可能随机出现还原失败的情况,且没有任何报错
   - 某些特殊方块（如床、门等多方块结构）可能需要特殊处理
   - 方块状态（如作物生长阶段）暂不支持还原
   - 容器类方块的内容不会被保存

3. 其他限制
   - 不支持保存多个还原点
   - 范围限制可能导致某些大型建筑无法完整记录
   - 某些命令方块和红石机构可能无法正确还原
   - 不支持跨维度记录和还原
